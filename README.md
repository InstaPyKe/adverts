# ViewEarn Kenya (adverts)

ViewEarn Kenya (`https://calcare.co.ke`) is a WhatsApp Status vehicle advertising marketplace connecting verified Kenyan car showrooms with registered status publishers.

## Features
- **Strictly Paid Publisher Plans**:
  - Starter Vehicle Tier (KSh 500 activation • KSh 25/view)
  - Growth SUV & Sedan Tier (KSh 1,500 activation • KSh 60/view)
  - Premium Executive Tier (KSh 3,500 activation • KSh 120/view)
- **Manual Safaricom M-Pesa Paybill Activation**:
  - Business Paybill Number: `522522`
  - Account Number: `VE-[User Phone]`
  - Payment proof verification by administrator.
- **Top Vehicle Listings & Cash Prices**: Popular Kenyan vehicle inventory with verified showroom cash prices, specs, and dealer hotlines.
- **Authorized 1080x1920 WhatsApp Status PNG Flyers**: High-resolution flyer export generated directly in-browser.
- **Immediate Tracking & Direct Earnings**: Real-time calculation of earnings based on reported status views.
- **Secret Administrator Portal**: Hidden access via 6 taps on the footer copyright text (`admin@calcare.co.ke` / PIN `456123`).
- **Single-File Architecture**: Complete self-contained application in `index.html` with zero external dependencies.

## Getting Started
Open `index.html` directly in any modern web browser or host on any static web server.
